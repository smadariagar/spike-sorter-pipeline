# Automated Spike Sorting Pipeline with SpikeInterface

This repository contains the necessary scripts to perform preprocessing, spike sorting, and visualization of microelectrode array (MEA) recordings. The workflow is built on the `SpikeInterface` framework and natively supports `.h5` (Multi Channel Systems) and `.rhs` (Intan) recordings.

## Directory Structure

```text
├── data/
│   ├── recording_file.h5
│   └── sorter_results/          # Automatically generated by the script
│       ├── cached_binary_...    # Temporary preprocessed data
│       ├── sorting_...          # Raw sorter results (Kilosort/MountainSort)
│       └── waveforms_...        # Extracted waveforms for analysis
├── src/
│   ├── fast_spikeinterface.py
│   ├── spikeinterface_waveform_ui.py
│   └── mea_mapping.json
└── README.md



Scripts Description

fast_spikeinterface.py.

    This is the main script for running the pipeline.
        File selection: Opens a graphical user interface (Tkinter) that allows the user to select one or multiple files simultaneously to be concatenated and batch-processed.
        Electrode mapping: Automatically calls the mea_mapping.json file to assign the correct 2D geometry of the MEA based on the input format (H5 or RHS).
        Memory Management: Due to the high RAM consumption typical of these recordings, the script applies filters (bandpass 300-6000 Hz) and saves a binary version in a local cache (cached_binary) before feeding the data to the sorter. This prevents system crashes (Out-Of-Memory errors).
        Sorter Configuration: The algorithms (e.g., Kilosort4, MountainSort5) and their hyperparameters are defined directly in the script's editing zone.
        Output: Generates all subfolders within sorter_results in the same directory where the source data is located.

spikeinterface_waveform_ui.py

    This script focuses on metadata extraction and results visualization.
        Usage: Upon execution, a dialog box will open. You must select the waveforms_... folder (generated in the previous step).
        CSV Extraction: Iterates through the data and exports a spike_list.csv file in the same folder, tabulating the Unit_ID, main channels, and exact spike times (in seconds) for each found neuron.
        Visualization: Automatically launches the spikeinterface-gui graphical interface, enabling manual inspection of the PCA, waveforms, correlograms, and quality metrics.

mea_mapping.json

    Contains the geometric architecture of the electrode array.
        Multiple configurations: Defines two distinct mappings: channel_mapping_h5 and channel_mapping_rhs.
        Technical justification: These maps differ because the data acquisition systems from Multi Channel Systems (H5) and Intan (RHS) route the hardware map of the physical channels to their linear (1D) data stream in completely different orders. This JSON acts as a translator to ensure that the physical XY coordinates match the correct electrical signal, regardless of the equipment used.
